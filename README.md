# Merkle-Damgard hash construction second preimage attack using fixed points

This repo is part of lab work conducted in my master's degree to implement a second preiamge attack (Kelsey and Schneier attack) against a Merkle-Damgard construction
of a hash function that uses compression function using a Speck family block cipher.

Details about the project can be found [here](https://github.com/Snaggy-w/MoSIG_Crypto_TP/blob/main/fp/README.md)
